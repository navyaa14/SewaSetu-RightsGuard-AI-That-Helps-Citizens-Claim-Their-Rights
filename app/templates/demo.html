06 · Connect

Try it with your own assistant

Any MCP client that supports OAuth works. It finds the sign-in on its own from the server's metadata.

Citizen
claude mcp add --transport http sewasetu {{ citizen_url or (portal_url + '/citizen/mcp') }}
  1. Ask it to apply for the old age pension. On the first call it opens the portal's sign-in page.
  2. Enter the applicant's mobile and the OTP{% if portal_url %} (in this simulation, OTPs appear at /__gateway/){% endif %}.
  3. Approve on the portal's consent page. The token works only for this server and ends after 2 hours.
Block officer
claude mcp add --transport http sewasetu-officer {{ officer_url or (portal_url + '/officer/mcp') }}
  1. Sign in with a departmental login. Each officer sees only her own block.
  2. Ask what is waiting, review a case with its age proof, then approve or reject with a reason.
  3. Every decision is recorded in the audit trail against the officer's name, exactly as on the web.
